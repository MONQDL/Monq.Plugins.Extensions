# Monq.Plugins.Extensions
Набор переиспользуемых расширений, парсеров и утилит для разработки плагинов MONQ Agent.

`Monq.Plugins.Extensions` — это .NET-библиотека с готовыми компонентами, которые дополняют
[`Monq.Plugins.Abstractions`](https://github.com/MONQDL/Monq.Plugins.Abstractions) и упрощают
реализацию типовых задач в плагинах MONQ Agent.

Репозиторий задуман как общее место для переиспользуемых решений: парсеров, форматтеров,
хелперов и прочих утилит, которые не привязаны к конкретному плагину и могут использоваться
несколькими плагинами одновременно.

На данный момент библиотека содержит:

- **`PrometheusParser`** — терпимый парсер и форматтер строк метрик в текстовом формате
  Prometheus (exposition format).

## Содержимое

### PrometheusParser

Самодостаточный класс (без внешних зависимостей) для работы с текстовым форматом Prometheus.
Задуман как общее решение для плагинов двух типов:

- **«генератор»** — ```MetricLine(...)``` рендерит метрики в строки для артефакта metrics.
Формат строгий: строки парсит Fennel-парсер агента.
- **«парсер»** — парсер — ```TryParseLine(...)``` читает чужой /metrics, добавляет лейблы и при
необходимости переиздаёт через ```MetricLine(...)```. Битые строки пропускаются, задача не падает.

#### Контракт формата
```
name{label="value",...} value [timestamp_millis]
```

- **имя метрики:** `[a-zA-Z_:][a-zA-Z0-9_:]*`
- **имя лейбла:** `[a-zA-Z_][a-zA-Z0-9_]*`
- **значение лейбла:** в кавычках, экранированы `\`, `"`, `\n`, `\r`, `\t`
- **значение метрики:** `float` в инвариантной культуре; `NaN` рендерится как `Nan`
  (единственная форма, которую разбирает парсер агента); `±Infinity` не представляются
- **timestamp:** целые миллисекунды Unix-времени

#### Возможности

- **`MetricLine(...)`** — рендерит строку метрики с валидацией имени метрики и имён лейблов.
  Бросает `ArgumentException` на невалидных именах и на `±Infinity` в значении.
- **`TryParseLine(...)`** — парсит одну строку метрики. Терпимый: для не-метрических строк
  (HELP/TYPE/комментарии/пустые) и некорректных строк возвращает `false` вместо исключения.
- Экранирование и разэкранирование значений лейблов согласно exposition format.
- Форматирование значений в инвариантной культуре.
