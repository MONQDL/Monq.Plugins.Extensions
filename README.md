# Monq.Plugins.Extensions
Набор переиспользуемых расширений, парсеров и утилит для разработки плагинов MONQ Agent.

`Monq.Plugins.Extensions` — это .NET-библиотека с готовыми компонентами, которые дополняют
[`Monq.Plugins.Abstractions`](https://github.com/MONQDL/Monq.Plugins.Abstractions) и упрощают
реализацию типовых задач в плагинах MONQ Agent.

Репозиторий задуман как общее место для переиспользуемых решений: парсеров, форматтеров,
хелперов и прочих утилит, которые не привязаны к конкретному плагину и могут использоваться
несколькими плагинами одновременно.

На данный момент библиотека содержит:

- **`PrometheusParser`** — терпимый парсер и форматтер строк метрик в текстовом формате
  Prometheus (exposition format).
- **`DelimitedRecordFramer`** — сборщик записей, разделённых произвольной последовательностью
  байтов, из фрагментированного потокового ввода.
- **`TcpListenerHost`** — общий цикл TCP listener с параллельной обработкой клиентов.

## Содержимое

### PrometheusParser

Самодостаточный класс (без внешних зависимостей) для работы с текстовым форматом Prometheus.
Публичные типы находятся в пространстве имён:

```csharp
using Monq.Plugins.Extensions.Prometheus;
```

Класс поддерживает два основных сценария:

- **генерация** — `MetricLine(...)` формирует нормализованные строки для metrics-артефакта;
- **обогащение** — `ParseText(...)` или `TryParseLine(...)` разбирают внешний `/metrics`,
  после чего в `ParsedMetric.Labels` можно добавлять, заменять и удалять лейблы.

#### Контракт формата
```
name{label="value",...} value [timestamp_millis]
```

- **имя метрики:** `[a-zA-Z_:][a-zA-Z0-9_:]*`
- **имя лейбла:** `[a-zA-Z_][a-zA-Z0-9_]*`
- **значение лейбла:** в кавычках, экранированы `\`, `"`, `\n`, `\r`, `\t`
- **значение метрики:** число с плавающей точкой в инвариантной культуре, `+Inf`, `-Inf`,
  `Nan` или `NaN`; при разборе обе формы NaN представлены как `Value == null`;
- **timestamp:** необязательные целые миллисекунды Unix-времени в диапазоне `DateTimeOffset`.

#### Возможности

- **`MetricLine(...)`** — рендерит строку метрики с валидацией имени метрики и имён лейблов.
  лейблы с `null`-значением не выводятся;
  `NaN` выводится как `Nan`; `±Infinity` выводятся как `+Inf` и `-Inf`.
- **`TryParseLine(...)`** — разбирает одну строку метрики. Для HELP, TYPE, комментариев,
  пустых и синтаксически некорректных строк возвращает `false`.
- **`ParseText(...)`** — за один проход разбирает все метрики из текста `/metrics` без
  промежуточного `Split`; неподходящие строки пропускаются.
- **`ParsedMetric.Labels`** — изменяемый словарь: после разбора можно добавлять, заменять
  и удалять лейблы.
- Парсер принимает пустой блок `{}`, хвостовую запятую в блоке лейблов, окружающие пробелы
  и обе формы `Nan`/`NaN`; при повторной генерации представление нормализуется.
- Экранирование и разэкранирование значений лейблов согласно exposition format.
- Форматирование значений в инвариантной культуре.

#### Добавление собственных лейблов

```csharp
var metrics = PrometheusParser.ParseText(responseText);

foreach (var metric in metrics)
{
    metric.Labels["environment"] = "production";
    metric.Labels["agent"] = "monq-01";

    if (metric.Value is not double value || metric.Timestamp is not DateTimeOffset timestamp)
        continue;

    var line = PrometheusParser.MetricLine(
        metric.Name,
        value,
        metric.Labels,
        timestamp);
}
```

Метрики без timestamp можно разбирать и передавать дальше как структурированные данные, но
текущая перегрузка `MetricLine(...)` требует явно указать timestamp. Для `Nan`/`NaN` значение
равно `null`; политику повторной публикации такого значения определяет вызывающий код.

### DelimitedRecordFramer

`Monq.Plugins.Extensions.Net.Tcp.DelimitedRecordFramer` собирает полные записи из
произвольных блоков данных. Разделитель может находиться между двумя блоками. Записи больше
заданного ограничения пропускаются, после чего обработка продолжается со следующей записи.

Класс не зависит от TCP и подходит для любого байтового потока. Управление соединением,
повторные подключения и интерпретация полученных записей остаются ответственностью плагина.

### TcpListenerHost

`Monq.Plugins.Extensions.Net.Tcp.TcpListenerHost` принимает TCP-соединения и передаёт
каждое соединение асинхронному обработчику. Количество одновременно работающих обработчиков
не ограничивается библиотекой; при остановке listener ожидает завершения уже принятых клиентов.
Разбор протокола, обработка ошибок клиента и публикация результата остаются ответственностью плагина.
